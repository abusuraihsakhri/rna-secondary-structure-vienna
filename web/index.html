Method and limitations

    
This offline tool uses the Nussinov dynamic-programming algorithm to maximize the number of AU, GC and GU pairs, requiring at least three unpaired nucleotides inside hairpin loops. It predicts pseudoknot-free structures, not thermodynamic minimum free energy; it does not use stacking energies, Turner parameters or partition functions.

    
For thermodynamic folding, install the repository's optional ViennaRNA Python bindings and run the fold CLI or local /api/fold endpoint. Source and usage.
